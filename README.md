# Go Task Manager

Учебная консольная программа для работы со списком задач.

## Возможности

- Несколько задач, заданных в коде.
- Вывод списка всех задач.
- Фильтрация по статусам: `новая`, `в работе`, `завершена`.
- Консольное меню и выход из программы.

## Запуск

Требуется Go версии, указанной в `go.mod`.

```sh
go run .
```

## Проверка

```sh
go vet ./...
go test ./...
```

Автоматические тесты пока не добавлены.
